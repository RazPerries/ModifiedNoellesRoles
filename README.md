## A modified version of Noelles Roles by agmas. This is an addon to the Harpy Express by doctor4t and requires the HarpyModLoader by agmas to function.

## Role List:

### Killers
- Morphling

- Phantom

- Swapper

### Accomplices
Accomplices are killer-sided roles that can either become a killer or contribute to killer's wins.

- Jester

- Executioner

- Vulture

### Civillians

- Conductor

- Bartender

- Noisemaker

- Recaller

- Coroner

- Voodoo

### Joke Roles (disabled by default)

- Awesome Binglus
  - Awesome Binglu
  - Spawns with a lot of notes
- The Insane Damned Paranoid Killer Of Doom Death Destruction And Waffles
  - Killer Role
  - Can hear ghosts
- Better Vigilante
  - Spawns with a grenade

### Extras
- Coroner's ability can be used by spectators when looking at a body
- (Configurable) Players will start morphing skins and have a hidden name when having extremely low mood.

### Config Note
Use /setEnabledRole and /listRoles (from HarpyModLoader) to enable or disable roles.
